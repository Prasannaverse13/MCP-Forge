How it works

The agent keeps going until the tests pass.

Most generated tool code fails on the first run. MCP Forge expects that. It runs real tests, reads the failures, and fixes its own code before it hands you anything.

  • Find the docsTavily search pulls the current API pages.
  • Write the serverNemotron Super drafts tools and schemas.
  • Run the testsA Nebius Serverless Job runs them in isolation.
  • Fix and shipNemotron Nano patches failures, then it deploys.
